# 你今天需要做的事情

自动准备已经完成。你只需要做下面三件事，总计约 20～30 分钟。

## 1. 填入模型 API Key

推荐先使用阿里云百炼，因为当前项目已经按 OpenAI 兼容接口配置好文本、视觉和 Embedding 模型。

打开：

```text
E:\AI-Agent-Projects\ResearchKB\.env
```

找到：

```env
OPENAI_API_KEY=
```

把自己的 Key 粘贴到等号后面。不要把 Key 发到聊天中，也不要修改 `.env.example`。

如果百炼控制台为你的业务空间提供了专属 API Host，同时替换 `OPENAI_BASE_URL`。默认公共北京地址已经写好。

## 2. 运行两条检查命令

在 PyCharm Terminal 或 PowerShell 中运行：

```powershell
cd E:\AI-Agent-Projects\ResearchKB
uv run python scripts\check_day1.py
uv run python scripts\check_cloud_models.py
```

第二条命令会产生三类结果：文本输出 `CLOUD_TEXT_OK`、视觉模型识别图表年份、Embedding 数量和维度。如果报错，完整复制错误信息即可，不要复制 `.env` 内容。

## 3. 在 PyCharm 中确认解释器

打开项目目录 `E:\AI-Agent-Projects\ResearchKB`，解释器选择：

```text
E:\AI-Agent-Projects\ResearchKB\.venv\Scripts\python.exe
```

然后阅读 `docs\样本资料清单.md`，从八个测试问题中任选两个，先自己在 PDF 中寻找答案。这一步是为了后续能判断 RAG 回答是否正确。
